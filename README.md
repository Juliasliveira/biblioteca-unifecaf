# Biblioteca Digital UniFECAF

Primeira versão da interface web da Biblioteca Digital UniFECAF, feita apenas com HTML e CSS
(disciplina Design Web).

## Estrutura
- `index.html`: conteúdo semântico da página
- `css/style.css`: layout, identidade visual e responsividade (mobile-first)
- `assets/imagens/`: ilustrações em SVG e favicon

## Seções (conforme o protótipo)
Menu, imagem principal, Sobre a nossa biblioteca (texto, imagem, texto + 4 miniaturas),
imagem larga, Nossos livros (6 cards), As unidades (3 unidades) e Contatos.

## Observação
Textos, horários, e-mail e telefone são fictícios, criados para fins acadêmicos.
